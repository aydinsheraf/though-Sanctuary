# Sanctuary — Fluid Thoughts & Global Echoes

**Sanctuary** is a serene, minimalist web app for sharing quotes, stories, and personal reflections in a calm digital space.

## ✨ Features

- **Fluid Momentum Carousel:** Smooth drag-and-swipe horizontal banner for browsing thoughts.
- **Ambient Canvas Background:** Floating particle engine for a living, peaceful background.
- **Atmospheric Themes:** Instant switching between **Moss**, **Amber**, and **Midnight** dark modes.
- **Real-Time Global Wall:** Shared quotes sync instantly across all visitors worldwide via Supabase.

## 🛠️ Built With

- **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Supabase (Serverless PostgreSQL)
- **Deployment:** Single-file architecture (`index.html`) hosted on GitHub Pages

## 🚀 Quick Setup

1. Fork or clone this repository.
2. Update `SUPABASE_URL` and `SUPABASE_ANON_KEY` inside `index.html`.
3. Enable **GitHub Pages** under repository settings.
